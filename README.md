# 🚀 AlgoFlow: Advanced AI Algorithm Analyzer & Visualizer

AlgoFlow is a professional-grade, AI-powered platform for analyzing, debugging, optimizing, and visualizing Data Structures and Algorithms. Unlike traditional visualizers, AlgoFlow leverages Groq AI (Llama 3 / GPT-OSS) to provide intelligent code analysis, optimization suggestions, execution tracing, and interactive visual learning experiences.

## 🎯 Why AlgoFlow?

AlgoFlow was built to help students and developers understand how algorithms work internally rather than simply viewing the final output. By combining AI-powered reasoning with interactive visualizations, the platform transforms algorithm learning into a practical, hands-on experience.

Whether you're preparing for coding interviews, learning Data Structures and Algorithms, or debugging your own solutions, AlgoFlow provides deep insights into algorithm behavior and performance.

## ✨ Key Features

### 🧠 AI-Powered Analysis & Optimization

* Detects logical errors and potential bugs in user-submitted code.
* Provides AI-generated explanations of algorithm behavior.
* Suggests optimized approaches and better algorithms.
* Helps improve time and space complexity.
* Offers corrected versions of buggy implementations.

### 💻 Professional Code Editor

* Built using Monaco Editor (the editor behind VS Code).
* Supports C++, Java, Python, and JavaScript.
* Syntax highlighting and code formatting.
* Automatic language detection.
* Developer-friendly coding environment.

### 📊 Interactive Algorithm Visualization

* Visual representation of algorithm execution.
* Step-by-step algorithm walkthrough.
* Easy understanding of logic flow and data movement.
* Ideal for learning and interview preparation.

### 📈 Complexity Analysis

* Displays Time Complexity and Space Complexity.
* Dynamic complexity comparison charts.
* Compare algorithm growth rates such as:

  * O(1)
  * O(log n)
  * O(n)
  * O(n log n)
  * O(n²)

### 🔗 Data Structure Visualizations

Supports visual learning for:

* Arrays
* Linked Lists
* Sorting Algorithms
* Searching Algorithms

### 📄 Educational Export System

* Download complete analysis reports as PDF.
* Includes:

  * Source Code
  * AI Explanations
  * Complexity Analysis
  * Visualizations

## 🚀 Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Gauravchaudhary76/AlgoFlow-Visualizer.git
cd AlgoFlow-Visualizer
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment Variables

Create a `.env` file in the project root:

```env
VITE_GROQ_API_KEY=your_groq_api_key_here
```

### 4. Start Development Server

```bash
npm run dev
```

---

## 🔑 Environment Variables

To run this project, add the following variable to your `.env` file and deployment platform (e.g., Vercel):

```env
VITE_GROQ_API_KEY=your_groq_api_key_here
```

You can obtain a Groq API key from:

https://console.groq.com
